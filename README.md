# Website quản lý và đặt món ăn trực tuyến cho nhà hàng

## Công nghệ sử dụng
- ReactJS + TypeScript
- TailwindCSS
- NodeJS + ExpressJS
- MongoDB
- JWT
- React-Leaflet + OpenStreetMap

## Chức năng chính
### Khách hàng
- Xem món ăn
- Giỏ hàng
- Đặt món
- Chọn vị trí giao hàng trên bản đồ
- Theo dõi trạng thái đơn hàng

### Admin
- Đăng nhập
- Quản lý món ăn, danh mục
- Quản lý đơn hàng
- Cập nhật trạng thái
- Xem vị trí khách hàng
- Thống kê doanh thu, giá vốn, lợi nhuận
